# Plan 01-01: Core Board State + GoL Rules Engine

Tracer slice for Phase 1. Must verify independently: types compiled, rules engine tested with known patterns, board constructed with correct dimensions, edge-aware neighbor counting validated. No game loop needed.

## must_haves

1. `Board` class owns a `Uint8Array[10000]` grid, initialized empty or random
2. `computeNextGeneration(input, w, h)` returns new `Uint8Array` — pure, no mutation
3. `countAliveNeighbors(board, x, y, w, h)` returns 3 for corners, 5 for edges, 8 for center
4. Blinker oscillates between horizontal/vertical over 2 ticks
5. Block (2x2) stays stable — zero changes after 1 tick
6. Glider moves correctly over 4 ticks
7. All tests pass: `bun test src/game/`

## Security Domain

Phase 1 has **zero attack surface**: no network I/O, no user input, no file system access beyond source files, no external dependencies, no `eval()`, no process spawning. Board size is fixed at 10,000 cells — no resource exhaustion path. `Uint8Array` is bounds-checked by the JS engine. Security review deferred until Phase 2 (WebSocket).

No security mitigations required for this plan.
